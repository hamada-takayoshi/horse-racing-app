# データベース概要 v3.1

## 1. 目的

過去10年を中心とする国内競馬データを収集・正規化し、過去分析と将来のレース予想の両方に利用できるデータ基盤を構築する。

## 2. 正本

- テーブル・カラム・制約の正本: `docs/tables/*.md`
- テーブル関連・カーディナリティの正本: `diagram/*.mmd`
- PNGは閲覧用の派生資料であり、差異がある場合はMarkdown/Mermaidを優先する。
- ER図の属性は主要項目のみの抜粋。完全な列定義はテーブル定義書を参照する。

## 3. データソース方針

公式確定値は `DataSource.Priority` / `AuthorityLevelCode` に基づいて1つの正規値を採用する。オッズ・独自指数・独自評価は、提供元ごとに複数値を並存させる。

## 4. Rawデータ方針

`RawContent` は原本内容、`RawFetch` は取得イベントを表す。RawContentはSHA-256ハッシュで重複排除し、RawFetchは取得のたびに追加する。初期リネージ対象はRace/RaceEntryだが、Rawデータ自体は全取得で保存する。

## 5. 初期スコープ外

- WIN5など複数レース型馬券
- 所属・馬主の履歴テーブル
- SourceMappingの外部ID変更履歴
- Race/RaceEntry以外の完全リネージ（段階導入）
